# 프라이버시 보호 비디오 압축기 — 설계 문서

**날짜:** 2026-09-26
**상태:** 승인됨

---

## 1. 목표

사용자의 브라우저에서만 비디오를 압축하는 프라이버시 중심 웹 애플리케이션을 구축한다. 서버 업로드 없이 모든 처리가 클라이언트 사이드에서 완료되며, 출력 파일 크기는 50MB (49.9MB)로 고정된다.

## 2. 핵심 요구사항

| 항목 | 내용 |
|------|------|
| 타겟 크기 | 50MB (49.9MB) 고정 |
| 인코딩 방식 | WebCodecs API |
| 출력 코덱 | AV1 |
| 출력 컨테이너 | WebM |
| 기능 범위 | 핵심 기능만 (파일 선택 → 압축 → 다운로드) |
| 프라이버시 | 서버 통신 없음, 외부 스크립트 없음, 완전 오프라인 동작 |

## 3. 기술 스택

- **단일 HTML 파일** (`index.html`): HTML + CSS + Vanilla JS
- **빌드 도구:** 없음
- **외부 의존성:** 없음
- **브라우저 API:** WebCodecs API (`VideoDecoder`, `VideoEncoder`), `File` API, `Blob`

## 4. 아키텍처

### 4.1 데이터 흐름

```
사용자 파일 선택
       ↓
File → Blob → ArrayBuffer
       ↓
VideoDecoder로 원본 분석 (길이, 해상도, 프레임레이트)
       ↓
타겟 크기(49.9MB) 기반 비트레이트 자동 계산
       ↓
VideoEncoder(AV1)로 인코딩 + 진행률 표시
       ↓
WebM 컨테이너로 저장 (Blob)
       ↓
다운로드 링크 제공
```

### 4.2 비트레이트 계산 공식

```
targetSizeBits = 49.9MB × 8 = 399,200,000 bits
videoBitrate = targetSizeBits / durationInSeconds
```

오디오 비트레이트(128kbps)를 고려하여 비디오 비트레이트에서 차감한다.

### 4.3 주요 컴포넌트

| 컴포넌트 | 역할 |
|----------|------|
| `FilePicker` | 파일 선택 UI, 드래그앤드롭 지원 |
| `VideoAnalyzer` | `VideoDecoder`로 원본 비디오 메타데이터 추출 |
| `BitrateCalculator` | 타겟 크기 기반 비트레이트 계산 |
| `VideoEncoder` | `VideoEncoder` API로 AV1 인코딩 수행 |
| `ProgressTracker` | 인코딩 진행률 및 예상 시간 표시 |
| `DownloadManager` | 결과 WebM 파일 다운로드 링크 생성 |

## 5. 사용자 인터페이스

### 5.1 화면 구성

1. **헤더:** 앱 이름 + 프라이버시 안내 배지
2. **메인 영역:**
   - 파일 선택 영역 (드래그앤드롭 + 클릭 선택)
   - 선택된 파일 정보 (이름, 크기, 길이, 해상도)
   - 압축 시작 버튼
3. **진행 영역:**
   - 진행률 바
   - 현재 상태 텍스트 (분석 중, 인코딩 중, 완료)
   - 예상 남은 시간
4. **결과 영역:**
   - 압축 전후 크기 비교
   - 다운로드 버튼
   - 새 파일 압축 버튼

### 5.2 프라이버시 안내

- 페이지 상단에 "서버 업로드 없음 · 브라우저에서만 처리" 배지 표시
- 모든 처리가 로컬에서 이루어짐을 명시

## 6. 오류 처리

| 오류 상황 | 처리 방식 |
|-----------|-----------|
| 지원하지 않는 비디오 포맷 | 사용자에게 지원 포맷 안내 (MP4, WebM, MOV 등) |
| AV1 인코딩 미지원 브라우저 | 브라우저 업그레이드 안내 메시지 |
| 비디오 길이 0 또는 메타데이터 추출 실패 | 오류 메시지 표시 |
| 인코딩 중 메모리 부족 | 사용자에게 안내 후 중단 |
| 이미 타겟 크기 이하인 파일 | 압축 불필요 안내, 원본 다운로드 제공 |

## 7. 보안 및 프라이버시

- **서버 통신 없음:** `fetch`, `XMLHttpRequest`, `WebSocket` 등 네트워크 API 사용 금지
- **외부 리소스 없음:** CDN, 외부 폰트, 외부 스크립트 로드 금지
- **파일 처리:** 모든 파일은 메모리에서만 처리, 디스크에 저장하지 않음
- **캐시:** 결과 파일은 `Blob` URL로 생성, 페이지 새로고침 시 자동 삭제

## 8. 브라우저 지원

| 브라우저 | 최소 버전 | AV1 인코딩 |
|----------|-----------|------------|
| Chrome | 94+ | 지원 |
| Edge | 94+ | 지원 |
| Safari | 16.4+ | 미지원 (인코딩) |
| Firefox | 130+ | 미지원 (인코딩) |

Safari 및 Firefox 사용자에게는 AV1 인코딩 미지원 안내를 표시한다.

## 9. 테스트 전략

- **수동 테스트:** 다양한 비디오 포맷(MP4, WebM, MOV) 및 크기로 압축 확인
- **경계 테스트:** 이미 49.9MB 이하인 파일, 매우 큰 파일(500MB+), 짧은 파일(10초 미만)
- **브라우저 테스트:** Chrome, Edge에서 정상 동작 확인
- **프라이버시 테스트:** 네트워크 탭에서 서버 통신 없음 확인
